# Security Policy

## Supported Versions

Only the latest release receives fixes. Update to it before reporting.

## Reporting a Vulnerability

Report privately through GitHub: open the [Security tab](https://github.com/PawelSzymanski89/flutter-ultimate/security) of this repository and click **Report a vulnerability** (private vulnerability reporting). Do not open a public issue for a vulnerability.

Include the affected file (scanner script, hook, command), the version, steps to reproduce and the impact you expect.

A wrong or missing finding from the scanner is not a vulnerability; use the false-positive issue form for that.
